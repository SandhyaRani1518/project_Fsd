# Hotel Booking Website

A web-development project for a hotel booking website. The repository contains HTML, CSS and JSP pages for the user-facing booking experience.

## Interface areas

The available pages and assets include:

- Hotel landing page and room browsing.
- User login and registration pages.
- Room and booking-related pages.
- Payment-related views.
- JSP pages and supporting web assets.

## Technologies

- HTML
- CSS
- JavaServer Pages (JSP)

## Repository structure

- `index.html`, `home.html`, `homepage.html` — landing and home pages.
- `login.html`, `login.jsp`, `signup.html`, `signup.jsp` — account interface pages.
- `rooms.html`, `REGISTER.HTML` — room and registration pages.
- `paymet.html`, `paymet.jsp` — payment-related pages.
- `WEB-INF/` — web application configuration.

## Notes

This repository contains an academic web-development project. The source should be reviewed and configured for the target servlet container and database, if required, before deployment. No production deployment or payment integration is claimed.
